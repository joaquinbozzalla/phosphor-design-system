DESIGN SYSTEM · CRT TERMINAL

Engineering docs
from a future that
already happened.

A brand-agnostic phosphor-green terminal system. Black screens, glowing green type, hand-drawn line geometries, restrained animation — modern and minimal at the same time.

● MODE: DARK + LIGHT SATOSHI / IBM PLEX MONO / VT323 SURFACE: WEB MONOCHROME + 1 ACCENT
01

Color

Monochromatic greens plus one amber accent. Never more than three hues on a single surface. No purples, no body-background gradients. Values resolve live from the active theme.

05

Motion

Every animation serves a verb — loading, revealing, confirming. The screen responds; the UI never fidgets. steps() easing for machine motion, springs for human motion. Respects prefers-reduced-motion.

[ CURSOR BLINK ] ready
[ TYPEWRITER ] > initializing phosphor array
[ SCAN SWEEP ]
06

Line geometries

Aerospace blueprints and Mesoamerican ornamental line art. Every motif ships dark (bright phosphor) and light (printed parchment) variants — the page swaps them with the theme.

07

Voice & anti-patterns

Terse, technical, slightly conspiratorial. Sentence-case headlines, UPPERCASE mono labels, lowercase terminal output. Numbers when you have them.

[ DO ]
✓Unicode blocks & bracket labels: ■ ▲ ●, [OK]
✓Elevation via phosphor glow, hairline borders do the work
✓Hover = brighten + glow, never scale or translate
✓"Shipped 14 production apps." — real numbers
[ DON'T ]
✕Emoji, filled/duotone icon sets, hand-drawn humans
✕Bluish-purple gradients or any body-background gradient
✕Soft pebble corners — buttons 8px max, modals 14px max
✕Gaussian drop-shadows in dark mode, loud scanlines
